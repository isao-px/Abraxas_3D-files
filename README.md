# Abraxas 3D Files

3D files of the Abraxas project, a lightweight and portable system developed to monitor inshore sailing training.
Main project available in the [Abraxas repository](https://github.com/isao-px/Abraxas).

## Raw files

Unsliced models of each part, provided in STEP and STL formats. They are suitable for modification or for use with any slicer.

| Part | STEP | STL |
|------|------|-----|
| Enclosure | `Boîte.step` | `Boîte.stl` |
| Anemometer | `Anémomètre.step` | `Anémomètre.stl` |

## Sliced files

The files `Abraxas.3mf` and `Abraxas.gcode` contain the complete project, with all parts included. They are prepared for the Creality K2 Plus.

| Parameter | Value |
|-----------|-------|
| Printer | Creality K2 Plus |
| Material | PLA |
| Supports | Not required |
| Total print time | 3 h 15 min |
| Filament length | 36.75 m |
| Filament weight | 109.61 g |

These values correspond to the latest version of the complete project.

The G-code is specific to the Creality K2 Plus and must not be used on another machine. For any other printer, use the 3MF file or the raw files, and slice them with the appropriate profile.

## OnShape file

The CAD source is available on [OnShape](https://cad.onshape.com/documents/6ee2d5825dfdeb777702c3c2/w/e5c4a30e407a88c70242bf14/e/ae243b618490c364e35ec324?renderMode=0&uiState=6ad33fcd79b2e3e3ffc387cb).

## Notes

PLA offers limited resistance to heat and prolonged exposure to sunlight. For permanent outdoor use, a more suitable material such as PETG or ASA may be considered, using the raw files.
